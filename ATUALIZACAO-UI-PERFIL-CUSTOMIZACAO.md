# Bluffin — atualização visual de perfil e customização

Esta atualização parte da versão `bluffin-perfil-estatisticas-correcao-v3`.

## Alterações
- Perfil e estatísticas agora usam um modal centralizado, com fundo escurecido e desfocado, cartão próprio, botão de fechar e conteúdo rolável.
- Customização agora tem layout em duas áreas: pré-visualização do alien e opções de cor/acessórios.
- A pré-visualização é atualizada quando uma cor ou acessório é selecionado.
- Layout responsivo: em telas pequenas, a prévia fica acima das opções.
- Cache atualizado no `index.html` para carregar os novos CSS e JS.

## Instalação
1. Faça backup da versão atual.
2. Extraia este ZIP mantendo a pasta `bluffin-work`.
3. Substitua os arquivos do projeto pelos arquivos extraídos.
4. Reinicie o servidor e atualize o navegador com `Ctrl + Shift + R`.

Não foram alteradas as regras das partidas, o sistema de suspeitos nem o armazenamento das estatísticas.
